## 1. 旧安装方式：开发期一律源码 link 安装

被删原文（`AGENTS.md` §红线 8，2026-10-13 前）：

```
   同版本重复打包不会刷新 pnpm 安装（integrity 判定「已最新」）——开发期一律源码 link 安装。
```

被改原文（`AGENTS.md` §常用命令，2026-10-13 前）：

```
bash scripts/install-to-dsh.sh    # 3082 link 安装（构建→冒烟→rm 旧→add→验证；不重启）
```

**删除原因**：这段把「源码 link 安装」写成开发期常态。2026-10-13 实测
`~/.dsh-dev/profiles/web/package.json` 中 `dsh-sudoku` 的依赖值是
`file:.../dsh-plugins/dsh-sudoku/dsh-sudoku-0.1.4.tgz`——**现行实装是 tgz**；
monorepo 纪律（`dsh-plugins/AGENTS.md`「安装（唯一方式 tgz，不用 link）」）同样是 tgz。
link 只是 `scripts/install-to-dsh.sh` 的历史实现（脚本尚未跟进，属未决项，
见 [../管理/PP-项目计划.md](../管理/PP-项目计划.md)「未决 / 待办」）。
