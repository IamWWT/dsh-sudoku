## 中途需求变更（2026-09-14，v0.1.1）

用户原话（对 3082 安装提问的回答中附带）：

> 「同时要有玩法简单介绍页面, 用户友好页面, 我看你截图的上面三个模式, 中最好设置为下拉模式, 要不然用户不知道自己现状什么模式处于. 另外, 横竖如在点击后有效果更新, 希望不同方向的效果还是有所差异, 且颜色最好有但是不要太刺激」

拆解为 v0.1.1 三项（登记后实施，见 tasks T11–T13）：

| # | 变更 | 实现口径 |
|---|------|------|
| C1（A7） | 面板增加「玩法简介」区 | 面板顶部可折叠区，默认展开，短规则说明（目标/选格/铅笔/撤销/提示/新一局），面向新用户友好文案 |
| C2（A8） | 难度三按钮 → `<select>` 下拉 | 选项文案「档位 · N 提示」，随时可见当前档位；切换仍走 `setDifficulty` 重开局 |
| C3（A9） | 行/列/宫高亮分方向差异化 | 选中格后：行=品牌色淡染、列=link 色淡染、宫=中性淡染（`color-mix` 8–12%，柔和）；级联优先级 宫>列>行 |

3082 安装：用户已确认并 link 安装；用户自行重启 3082（16:57 新 token 上线），进入实机使用阶段。

## 中途需求变更二（2026-09-14，v0.1.2，来自 3082 实机试用反馈）

用户原话：「1 已经重启 2 玩法简介默认折叠 3 需要支持全屏功能 4 用户写入的应该不同颜色展示 5 横竖线用不同阴影颜色显示 5 点击开始才能开始计时 6 最下面的最佳 <b>—</b> · 🏆 <b>0</b>胜 · 共 <b>1</b> 局 怎么有很多乱码的b 7 现在填入123..的方法不方便, 希望在上下左右各放一列数字方便用户填写, 以及这四列应该是不同颜色」

| # | 变更 | 实现口径 |
|---|------|------|
| C4 | 玩法简介**默认折叠** | `helpOpen` 初始 false，点「❓ 玩法简介」展开 |
| C5 | 全屏功能 | 标题行「⛶ 全屏」按钮：面板 `position:fixed` 铺满视口（z-index 置顶）再点退出；3084 实测覆盖效果 |
| C6 | 用户填数独立颜色 | 用户填数 = `--dsw-alias-link` 色；提示格保持 `label-primary` 加粗；同数字联动仍品牌色 |
| C7 | 横/竖线不同颜色 | 竖线 = 品牌色淡染、横线 = 链接色淡染（`color-mix` × `border-l2`），3×3 宫线同向加宽 |
| C8 | 计时须点「开始」 | 新增「▶ 开始」按钮：未点前棋盘锁定填数（可点选看高亮）、计时停 00:00；点击后起表+计局并解锁；新一局重置回「待开始」 |
| C9 | 修复成绩行 `<b>` 字面量 bug | 模板字符串里的 `<b>` 被 React 当纯文本渲染 → 改 `h("b")` 元素嵌套 |
| C10 | 四边数字键盘 | 棋盘上/下/左/右各一排 1–9（替代原底部单排），四边四色：上=品牌、右=链接、下=成功绿、左=琥珀（均 ~18% 淡染） |
