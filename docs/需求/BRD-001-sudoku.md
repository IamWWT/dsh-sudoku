## 1. 目标

在 DSH（DeepSeek Harness）Web GUI 的**右侧栏**提供一个纯客户端数独游戏标签「🧩 数独」，
作为 `dsh-minesweeper` 的姊妹插件：零运行时依赖、零网络请求、零后端状态（v0.1），
React 由宿主 `window.__ModuleLoader__` 注入，成绩只存浏览器 localStorage。

## 3. 引擎设计（`src/shared/engine.ts`，Host/Client 共享纯函数）

- **随机源注入**：`Puzzle.rng`（`newPuzzle` 注入；测试用 mulberry32 确定性回放）；引擎内部禁止直调 `Math.random`。
- **生成**：回溯法生成完整合法盘 → `removeClues` 挖洞：
  - 随机序、成对挖除（180° 旋转对称：i 与 80−i 同时挖/同时留）；
  - 每步 `countUpTo(puzzle, 2)` 唯一解校验，不唯一则回退（回滚挖洞）；
  - 多轮重排（≤4 轮）逼近目标提示数；搜索空间耗尽时提前停（实际提示数 ≥ 目标）。
  - **唯一解由构造保证**（挖洞校验），目标 <17 或 >81 直接抛错。
- **玩法**：`fillDigit`（0=清空；给定格不可改；**首填安全**：玩家首个数字若错误，引擎自动修正为解值并置 `firstFillCorrected`，UI 出 toast）；`toggleNote`/`clearNotes`（填格时 8 邻域自动清笔记）；`undo`（操作栈，上限 500，胜利后禁撤销）；`hint`（取第一个空格填正确值）。
- **胜负**：`filled==81 且全盘==解` → `state=won`（停表）；填错但不完整的盘面保持 playing（可修复），**无 lost 状态**。
- **冲突计算** `computeConflicts`：已填格中凡与同行/列/宫重复者全部标冲突（与给定格无关）。

## 5. 明确不做（v0.1 范围外）

- host 侧任何能力（`inject=[]`，`apply()` 空实现）；成绩文件持久化 → v0.2
- 自定义尺寸、每日挑战、分享棋谱、多主题皮肤（**全屏模式已由 v0.1.2 C5 转正，移出自本清单**）
- 计时器跨标签页持久化、联机/排行榜
